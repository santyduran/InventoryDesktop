# InventoryDesktop

Sistema de gestión de inventario para Windows.

## Instalación

Descarga el instalador desde la sección Releases.

Ejecuta `InventoryDesktop-Setup-1.0.0.exe` y sigue las instrucciones.

No necesitas instalar Node.js ni Visual Studio Code.

## Requisitos

- Windows de 64 bits.
- Espacio disponible para la instalación.
